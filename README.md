# Meenaa's Millionaire Club — website

Static site — plain HTML, CSS and JS, no framework. Clean URLs via folder-per-page, deployed to GitHub Pages by `.github/workflows/pages.yml` on every push to `main`.

- Pages: Home · About · Membership (21-category fee table with filters, also on Home) · Branches · Facilities · Gallery · Contact · Terms & Conditions (`/terms/`, linked from the footer and the fee notes)
- The enquiry and newsletter forms open the visitor's email app addressed to the Secretary (nothing is stored)

## Run locally

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080 (on a phone on the same Wi-Fi: `http://<this PC's IP>:8080`).

## Editing

The pages are generated by the scripts in `tools/` (one folder up, not deployed). Edit there and rebuild instead of hand-editing the HTML:

- `tools/build.py` — all page content and markup → `python tools/build.py`
- `tools/slots.py` + `tools/grade.py` — which photo goes where; `grade.py` colour-grades them to the logo's navy and gold and writes JPG + WebP (640/960/1280/1920) into `assets/img/photos/`. Source files are cached in `tools/raw/` (Unsplash now blocks scripted downloads, so keep that folder).
- `tools/fonts.py` — re-downloads the Google Fonts into `assets/fonts/`; `tools/subset_fonts.py` then trims them to the characters the pages use. Run `subset_fonts.py` again after adding text with new symbols or accented letters.

## Structure

- `404.html` uses absolute paths under `/MeenasClub/` (the GitHub Pages project path). Update them if the repo is renamed.
- Styles: `assets/css/style.css` · Fonts: `assets/css/fonts.css` + `assets/fonts/` (self-hosted, with size-matched fallbacks so text doesn't jump while fonts load)
- Scripts: `assets/js/main.js`, plain JS. Reveals, counters, the city accordion, the gallery lightbox, the enquiry-form dropdowns and a small scroll engine (hero drift, parallax, collage speeds, word-brightening statements, image-in-text drift) run on phones and desktops alike. Lenis smooth wheel-scrolling is desktop-only and loads from a CDN after the page is up.
- Dolphin animation (Home, "We rise together"): Lottie files in `assets/anim/`, played by `assets/js/vendor/lottie_light.min.js`, which loads only when that section is near the screen.
- Phones with ≤2 GB RAM or data-saver get a "lite" mode (class `lite` on `<html>`): the same animations, minus blur and the repaint-heavy effects. `prefers-reduced-motion` stops all movement but keeps gentle fades.
- Credits for the photos and animations are on `/terms/#credits` (the CC BY-SA photos need that credit kept).
